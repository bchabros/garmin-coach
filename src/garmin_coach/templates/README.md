# Athlete context

The athlete fills in `athlete-profile.md` over time, in their own language.
An empty heading means unknown; never invent a profile or copy another athlete's data.
The initial date records template creation, not an athlete assessment or a coaching review.
Numbers come from the database; this file holds qualitative context and decisions.

## Profile structure and history

Every edit requires approval of the exact diff, including the date-line change and
moves into the final decisions log. A declined or unanswered proposal leaves the file
unchanged. Replace current facts in place and preserve useful superseded decisions in
the dated final `Decyzje` log. Date temporary constraints and open threads. Above about 150 lines,
propose consolidation without silently dropping context.

Keep the `_Ostatnia aktualizacja: YYYY-MM-DD` date line below the title.
The profile, plans, reports, database and saved login are private personal state;
never publish them in a repository, plugin, issue or pull request.
