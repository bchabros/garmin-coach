# No emoji

Do not use emoji anywhere in this repository, or in output about it:

- documentation (README, `docs/`, PRDs, ADRs, glossary),
- code, comments, and docstrings,
- commit messages and PR/issue descriptions,
- chat responses discussing this repo.

Use plain text instead of decorative emoji. Write `Done`, not a check-mark
emoji; `Warning:` / `Note:`, not a warning or memo emoji; a `-` or `*` bullet,
not a pointer emoji.

Box-drawing characters (`├──`, `└──`, `│`) used for file-tree diagrams are not
emoji and are allowed.
